# Azeroth Travel Tracker

A dependency-free World of Warcraft: Classic addon for tracking estimated steps and travel distance.

This repository currently contains the initial addon namespace, metadata, test harness, and beta interface synchronization tool.

Future UI work will use a compact, uncrowded layout and place the main window on `FULLSCREEN_DIALOG` frame strata, or the highest safe non-tooltip strata supported by the beta client.
